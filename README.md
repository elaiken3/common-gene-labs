# Common Gene Labs

Common Gene Labs is an independent lab building human-centered tools for starting, focus, and emotional friction.

We design calm, supportive systems that meet people where they are — especially on hard days.

## Values
- We do not ship features that add pressure
- We design for variability, not ideals
- We explain why things exist
- We default to less
- We build with people, not at them

## Current Project
**With You** — a gentle companion for moments of overwhelm and task paralysis.

Built by Common Gene Labs.
